# 相关性分析

## Purpose
量化两个或多个变量间的线性相关程度，辅助判断变量间关系。

## 使用场景
用户要求分析两个变量的关系（如销售额与利润）、找相关性强的变量。

## 输入
含多个数值字段的数据集。

## 输出
相关系数 + 相关强度/方向解读。

## 执行步骤
1. 用 calculate_correlation 计算两列相关系数或全量相关系数矩阵。
2. 按强度分级解读：|r|≥0.8 极强、0.6-0.8 强、0.4-0.6 中等、0.2-0.4 弱、<0.2 极弱。
3. 画散点图看关系形态（线性/非线性）。
4. 结合业务解释相关方向与可能原因。

## 注意事项
- 相关 ≠ 因果，可能存在混淆变量或反向因果。
- r 接近 0 不代表无关系（可能是非线性关系）。
- 极端值会扭曲相关系数，必要时先剔除。

## 常见错误
- 把高相关直接等同于因果。
- 对类别变量直接算皮尔逊相关系数。

## 示例
sales 与 profit 相关系数 0.82（强正相关）→ 利润随销售同向变化，销售下滑是利润下滑的主因。
