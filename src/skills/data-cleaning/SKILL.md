# 数据清洗

## Purpose
在正式分析前识别并修复数据质量问题，保证后续分析结论可靠。

## 使用场景
用户要求清洗数据、检查数据质量、处理缺失值/重复值/异常值，或在分析前需要预处理。

## 输入
一个数据集（CSV/Excel/JSON），可能含缺失、重复、类型错误、异常值。

## 输出
数据质量报告 + 清洗后的干净数据。

## 执行步骤
1. 用 profile_dataset 检查缺失值比例、字段类型、唯一值。
2. 用 execute_python 定位缺失值、重复记录的具体分布。
3. 制定清洗策略：缺失值删除或填充、重复记录去重、类型强制转换。
4. 执行清洗并输出清洗前后对比（行数、缺失数变化）。
5. 说明保留或剔除异常值的业务依据。

## 注意事项
- 清洗前先量化问题规模，不要盲目删除。
- 填充缺失值要说明填充策略（均值/中位数/众数）。
- 类型转换失败的值应标记，不要静默丢弃。

## 常见错误
- 把关键业务字段的缺失值一律删除，导致样本严重偏少。
- 未检查重复记录就去重，误删有效数据。
- 用均值填充偏态字段（应使用中位数）。

## 示例
清洗 sales 数据：发现 discount 字段有 3% 缺失 → 用 0 填充；发现 5 条完全重复 → 去重。
