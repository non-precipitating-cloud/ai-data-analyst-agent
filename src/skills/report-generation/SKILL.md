# 报告生成

## Purpose
把分析过程、核心发现、异常、趋势、原因、建议整理成结构化报告。

## 使用场景
用户要求生成报告、汇报分析结论、输出总结。

## 输入
分析过程中产生的观察、工具结果、洞察、图表。

## 输出
一份结构化的 Markdown 分析报告。

## 执行步骤
1. 收集分析目标、数据概览、数据质量、核心发现、异常、趋势、图表。
2. 按固定章节组织：概览/数据质量/目标/过程/核心发现/异常/趋势/图表/原因/建议/限制。
3. 生成必要的图表并引用真实存在的图表文件。
4. 给出有数据支撑的原因分析与可落地建议。
5. 用 save_report 保存报告。

## 注意事项
- 报告所有结论必须基于真实数据，不得编造。
- 图表说明只引用真实生成的图表，不虚构。
- 区分「事实发现」与「原因推断」，推断要标注。

## 常见错误
- 罗列数据不加解读，缺乏原因与建议。
- 虚构未生成的图表或编造数字。

## 示例
报告包含 11 个章节，核心发现按贡献度排序，建议分紧急/短期/中长期。
