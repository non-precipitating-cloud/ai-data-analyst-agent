# 财务分析

## Purpose
从收入、成本、费用三个层面拆解利润变化，评估盈利能力。

## 使用场景
分析利润下降/上升原因、找利润率最低的产品/地区、成本费用诊断。

## 输入
财务数据（收入、成本、费用、利润等字段，可能按部门/科目/时间拆分）。

## 输出
利润变化归因 + 盈利能力指标（毛利率、净利率等）。

## 执行步骤
1. 利润 = 收入 - 成本 - 费用，先看三者的绝对变化。
2. 毛利率 = 毛利/收入、净利率 = 净利/收入，对比各维度。
3. 分科目/部门下钻，定位成本或费用异常项。
4. 找利润最低（或负利润）的产品/地区/部门。
5. 判断是收入端问题还是成本/费用端问题。

## 注意事项
- 关注利润与收入的匹配性：收入增利润不增 → 成本或费用失控。
- 分科目下钻，避免只看总量。

## 常见错误
- 只报利润总额，不拆解收入/成本/费用。
- 忽略毛利率变化，只看净利（可能被费用掩盖）。

## 示例
收入下降 12% 但利润下降 22% → 说明除收入下滑外，成本或费用占比上升，需进一步下钻费用科目。
