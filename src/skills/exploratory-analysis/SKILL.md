# 探索性分析

## Purpose
快速建立对数据集的整体理解：规模、结构、分布、趋势，为深入分析打基础。

## 使用场景
拿到一个新数据集、需要了解数据概况、看趋势/分布/对比时。

## 输入
一个数据集。

## 输出
数据概览（行数/列数/字段/缺失/分布）+ 关键趋势与分布特征。

## 执行步骤
1. read_dataset / inspect_schema 看规模与字段。
2. profile_dataset 看缺失、唯一值、数值统计。
3. 用 execute_python 按关键维度（时间/类别）聚合看趋势与分布。
4. 用 generate_chart 画趋势图、分布图、对比图。
5. 总结数据的整体特征与值得深挖的点。

## 注意事项
- 先看数据分布再下结论，避免被极端值误导。
- 关注均值与中位数的差异，判断是否偏态。

## 常见错误
- 只报均值不报分布，掩盖了偏态与异常。
- 忽略时间维度，把长期趋势当成整体均值。

## 示例
分析销售额：先按月聚合看 2024 vs 2025 趋势，再按地区/品类对比。
