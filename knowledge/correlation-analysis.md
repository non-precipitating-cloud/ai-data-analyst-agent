# 相关性分析

## 皮尔逊相关系数
衡量两个连续变量的线性相关程度，取值 -1 到 1。
- |r| ≥ 0.8：极强相关
- 0.6 ≤ |r| < 0.8：强相关
- 0.4 ≤ |r| < 0.6：中等相关
- 0.2 ≤ |r| < 0.4：弱相关
- |r| < 0.2：极弱或无相关
- 皮尔逊相关系数计算方法：r = Σ((xi - x̄)(yi - ȳ)) / [√Σ(xi - x̄)² × √Σ(yi - ȳ)²]
- 三步计算就是首先把每个点减去均值（中心化），再看两个偏差是’同号‘还是’反号‘，最后除以两边波动的乘积（归一化）


## 解读
- r > 0：正相关（同增同减）；r < 0：负相关。
- 相关系数高 ≠ 因果关系，可能存在混淆变量或反向因果。
- 相关性可能非线性：r 接近 0 不代表没有关系（可能是非线性关系）。

## 应用
- 销售与利润通常强正相关：利润随销售同向变化。
- 折扣与利润通常负相关：折扣越大，利润越低。
- 用于验证变量间关系，辅助归因分析。

## 注意事项
- 计算前先确认变量是连续数值型，类别变量需先编码或分组。
- 极端值会扭曲相关系数，必要时先剔除或做稳健相关。
