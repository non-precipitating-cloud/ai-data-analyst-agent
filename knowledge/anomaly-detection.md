# 异常检测

## Z-score 方法
z = (x - mean) / std，通常 |z| > 3 判定为异常（近似正态分布下）。
- 优点：简单直观。
- 缺点：对极端值敏感（极端值会拉高 std，掩盖异常）。
- std是standard deivation，标准差，衡量数据波动程度的指标，表示数据点平均偏离均值有多远

## IQR（四分位距）方法
IQR = Q3 - Q1，异常界限 = Q1 - 1.5×IQR 到 Q3 + 1.5×IQR 之外。
- 优点：对偏态数据稳健。
- 缺点：阈值较主观（1.5 或 3 倍可调）。
- IQR是interquartile Range，四分位距，另一种衡量数据离散程度的方法，比标准差更抗极端值
- Q1是四分之一分位（下四分位数依次Q2,Q3分别为中位数和上四分位数）

## 业务视角判断异常
- 检查异常值的分布：集中在某年份/地区/产品，可能是录入错误或促销活动。
- 单笔极端高值：可能是批量采购、数据错误，也可能是真实大单。
- 折扣异常（如 >80%）：通常是录入错误或特殊审批。

## 异常处理策略
- 先定位原因，再决定剔除、修正或保留。
- 剔除异常值后重新计算趋势，评估异常值对结论的影响幅度。

## 注意事项
- 异常 ≠ 错误，需结合业务判断。
- 检测前先看分布形态，选择合适的阈值与方法。
