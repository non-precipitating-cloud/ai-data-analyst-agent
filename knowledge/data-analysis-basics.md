# 数据分析基础

数据分析的一般流程：明确目标 → 数据采集与理解 → 数据清洗 → 探索性分析（EDA）→ 建模/统计 → 结论与建议。

## 常见分析类型
- 描述性分析：回答「发生了什么」，用均值、中位数、分布、占比等描述现状。
- 诊断性分析：回答「为什么发生」，通过维度下钻、对比、归因定位原因。
- 预测性分析：回答「未来会怎样」，用趋势外推、回归、时间序列。
- 处方性分析：回答「该怎么做」，给出行动建议。

## 常用维度拆解方法
- 同比：与去年同期对比，消除季节因素，适合评估年度趋势。
- 环比：与上一周期对比，反映近期变化。
- 贡献度拆解：某维度下降金额 ÷ 总下降金额，量化各维度对总变化的影响。

## 注意事项
- 分析前先做数据画像：行数、列数、字段类型、缺失值、唯一值、数值分布。
- 区分「相关」与「因果」，数据只能支持相关性，因果需要业务验证。
- 结论必须基于真实数据，不要编造数字。
