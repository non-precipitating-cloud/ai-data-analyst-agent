# 财务分析

## 利润分析
利润 = 收入 - 成本 - 费用。
- 毛利 = 收入 - 销售成本；毛利率 = 毛利 / 收入。
- 净利 = 毛利 - 期间费用（销售费用、管理费用、研发费用等）。

## 盈利质量指标
- 毛利率：衡量产品或服务本身的盈利能力。
- 净利率：衡量企业整体盈利能力。
- 收入成本比：成本 / 收入，越低越好。

## 利润下降诊断
1. 收入端：收入下滑直接拖累利润。
2. 成本端：销售成本上升挤压毛利。
3. 费用端：市场/研发/管理费用扩张。

## 杜邦分析思路
净资产收益率 = 净利率 × 总资产周转率 × 权益乘数，从盈利、运营、杠杆三个维度拆解。

## 注意事项
- 关注利润与收入的匹配性：收入增长但利润不涨，往往成本或费用失控。
- 财务分析应分科目、分部门下钻，避免只看总量。
